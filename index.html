Features

复刻每一处质感细节

从传感器映射到渲染管线，都和网页端的原版逻辑保持一致。

陀螺仪驱动折叠

原生加速度计经 JS 桥驱动 WebView 渲染内核，映射公式与网页端逐行一致（sign=-1 + 指数平滑），倾斜时画面随之折叠。

真实景深模糊

采用 Gaussian 金字塔实现折叠处的景深虚化，越靠近铰链模糊越重，边缘带透视缩短，观感贴近真实物理折页。

铰链黑边 + 玻璃反光

铰链处叠加黑边渐变，面板带高光反射，把"折起来"的层次和玻璃质感一并还原。

WebView / WebGL2 内核

渲染完全内嵌浏览器内核，避开原生 GLES 兼容性差异，几乎全设备可用。

复古简约 UI

全字体思源宋体（Noto Serif CJK）· 黑底米白 · 白描边品牌 Logo，打开即是成品观感。

液态玻璃底栏

iOS 26 Liquid Glass 风格悬浮 Tab 栏：Haze 真实背景模糊 · 顶部渐变高光 · 弹性液态选中 Pill。

How it works

四步，从截图到折叠

打开应用，选一张截图，剩下的交给陀螺仪。

选择截图

从相册挑选手机桌面截图，或通过系统相册（Photo Picker）直接选取。

全屏沉浸

点击图片进入全屏效果页，画面即刻铺满整块屏幕。

倾斜折叠

倾斜手机，折叠量随倾角从 0° 到 90° 连续变化，方向决定折向。

轻点退出

轻点屏幕 3 次（800ms 内），一步回到优雅主页。
